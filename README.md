# Real vs. Fake Face Detection (Deepfake)

This was a **Group Miniproject** for our third year of Engineering. Our team implemented a Deep Learning model to classify images as "Real" or "Fake" and deployed it as a simple web app.

**Tools & Technologies:** Python, TensorFlow, Keras, **EfficientNet B0**, OpenCV, **Gradio**

---

### Project Workflow & Explanation

As a team, our goal was to learn and implement the full end-to-end pipeline for deepfake detection.

#### **1. Context (The Problem)**
Deepfakes, media generated by AI, are a growing problem. Our project's goal was to build a classifier that could accurately identify this manipulated media.

#### **2. Action (Our Team's Process)**
Our group's process involved several key steps:

1.  **Data Preparation (from `Dataset_link.txt`):** The model was trained on a dataset of real and fake face images.
2.  **Face Detection (Pre-processing):** A model like MTCNN is used to detect and crop the face from each image, so the classifier only analyzes the relevant features.
3.  **Model Training (EfficientNet B0):**
    * We used the **EfficientNet B0** model, a powerful and lightweight Convolutional Neural Network (CNN).
    * We applied **Transfer Learning** by using the model's pre-trained weights (from ImageNet) and re-training the final layers on our specific "Real vs. Fake" dataset.
    * Our final trained model was saved as `real_ai_classifier.keras`.
4.  **Deployment (Gradio):**
    * Using the `Gradio_final.ipynb` notebook, we loaded the saved `.keras` model.
    * We built a simple, interactive web interface using the **Gradio** library, which allows a user to upload an image and get a real-time prediction.

#### **3. Result (What We Learned)**
* Our team learned how to implement a complex deep learning pipeline.
* We gained practical experience with **Transfer Learning** using a state-of-the-art model (EfficientNet B0).
* We learned how to **deploy a model** as a usable web application, bridging the gap from a notebook to a real product.

#### **4. Impact (The Takeaway)**
This project demonstrates our team's ability to work together to learn and apply advanced Deep Learning and Computer Vision techniques to solve a real-world problem.
